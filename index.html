Privacy Policy — Specifications Agent v0.3

Last updated: August 8, 2026

Overview

Specifications Agent v0.3 uses a custom API action to retrieve structured ISASP Reading specification data. The API is used only to look up specification information based on the inputs supplied by the user.

Information Sent to the API

The action sends only:

  • Grade
  • Content area
  • Genre

The API does not require student names, student records, student responses, demographic information, passwords, financial information, or other personally identifiable information.

How the Information Is Used

The submitted lookup fields are used only to retrieve the matching assessment specification and return it to the user.

Data Storage and Retention

The Specifications Agent API is not designed to create user profiles or store personal information submitted through the action. Standard infrastructure logs may be generated by the hosting platform for service operation, troubleshooting, security, and reliability.

Third-Party Services

  • OpenAI / ChatGPT for the Custom GPT interface
  • Render for API hosting
  • GitHub for code and project version control

Use of those services is also subject to their respective privacy and security practices.

Sensitive Information

Do not submit student-level information, personally identifiable information, unreleased operational assessment content, answer keys, confidential reviewer notes, passwords, API keys, or other sensitive information to this prototype.

Changes to This Policy

This policy may be updated as the Specifications Agent is expanded or its hosting and data-handling practices change.
